# Effective Altruism at Illinois

The complete current website is in [website/](website/). Start with [the hosting guide](website/HOSTING.md) to deploy the app to Cloudflare Workers with D1 and connect eaillinois.org.

The root index.html, logo, and Google verification files are the previous static site and have been preserved. The full app is not served by that root index.html or by GitHub Pages automatically.

From a clone, run cd website before following the guide. GitHub stores source; private names, emails, feedback, and attendance records belong only in the private database. No database export or credentials are included.

Email signup records addresses; automated email delivery is not configured.
